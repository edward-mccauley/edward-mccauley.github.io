## Professional Self-Assessment

Completing the Computer Science program and developing this ePortfolio helped me connect my previous technical experience with modern software development skills. Before completing this degree, most of my professional background came from more than 20 years of field service engineering, electronics troubleshooting, customer support, and military technical work. Those experiences taught me how to troubleshoot complex systems, communicate with customers and team members, work under pressure, and support technology that other people depend on. The Computer Science program helped me build on that foundation by strengthening my skills in programming, software engineering, databases, algorithms, testing, security, and system design.

One of my strengths is that I approach software from both a technical and practical perspective. My field service and military background taught me to think about how systems behave in the real world, not just how they are supposed to work in theory. Throughout the program, I learned to apply that mindset to software development. I became more comfortable reading existing code, identifying weaknesses, debugging errors, improving structure, documenting decisions, and explaining technical choices. These skills are important because professional software development is not only about writing code that runs. It is also about building software that is understandable, maintainable, secure, and useful to others.

The program also helped me improve how I communicate and collaborate in technical environments. Through discussions, peer responses, written assignments, and project documentation, I practiced explaining technical ideas clearly to different audiences. In software projects, communication is just as important as implementation because stakeholders need to understand what the software does, why design choices were made, and how the system can be maintained or improved. My code review, enhancement narratives, README files, and ePortfolio pages demonstrate my ability to communicate technical work in writing and organize it for both academic and professional review.

My coursework strengthened my understanding of software engineering and database development. I worked with object-oriented programming, full stack development, testing, secure coding, and database-driven applications. These experiences helped me understand the importance of separation of concerns, modular design, input validation, error handling, and documentation. In database-related coursework and projects, I gained experience working with MongoDB and designing applications that retrieve, organize, and present data in useful ways. These skills connect directly to the type of work I want to pursue in software engineering, cloud infrastructure, automation, and security.

Several courses outside of the capstone also helped prepare me for professional software development. Full stack development helped me understand how front-end, back-end, routing, templates, APIs, and databases work together in an application. Software testing coursework helped me think about expected behavior, edge cases, and how testing supports maintainability. Secure coding coursework reinforced the importance of input validation, error handling, and reducing common vulnerabilities. These experiences helped me see how different areas of computer science connect in real software projects.

The program also helped me develop stronger algorithmic thinking. Courses involving programming, data structures, and algorithms helped me practice breaking problems into smaller parts, choosing appropriate data structures, and using logic to process information. In my capstone enhancement, I applied this by improving a basic filtering process into a matching, scoring, and ranking system. This showed me that algorithms are not only academic exercises. They directly affect how useful and effective an application can be for decision-making.

Security also became a more important part of how I think about software. My secure coding coursework and capstone database enhancement reinforced that security should not be added at the end of a project. It should influence design decisions from the beginning. I practiced thinking about safer configuration handling, database query validation, controlled error handling, and limiting unnecessary exposure of sensitive information. This security mindset is especially important for my professional goals because I am interested in cloud engineering, networking, automation, DevOps, and eventually cloud security.

The artifacts in this ePortfolio fit together as a complete example of my growth as a computer science student and emerging technology professional. I selected the Grazioso Salvare Dashboard because it allowed me to demonstrate multiple areas of computer science in one connected project. The original artifact was a Python and MongoDB dashboard that displayed animal shelter data and supported rescue-animal selection. I enhanced the artifact in three categories: software design and engineering, algorithms and data structures, and databases.

The software design and engineering enhancement shows my ability to improve the structure of an existing application. I refactored the original dashboard into a more layered design with clearer responsibilities for application entry, database access, configuration, rescue filtering, and controller coordination. The algorithms and data structures enhancement shows my ability to use dictionaries, lists, conditional logic, scoring, and sorting to improve the rescue-animal selection process. The database enhancement shows my ability to improve MongoDB access through safer query construction, allowed field validation, projections, result limits, safer update handling, and environment-based configuration.

Together, these enhancements demonstrate my ability to improve existing software in a professional way. They show that I can analyze an artifact, identify areas for improvement, apply technical skills, document my decisions, and present the final work clearly. Completing this ePortfolio helped me become more confident in my ability to explain my work, support my decisions, and continue developing toward roles in cloud engineering, cloud networking, DevOps, automation, and cloud security.

## Capstone Focus

For my capstone project, I enhanced my Grazioso Salvare Dashboard artifact in three key areas:

* Software design and engineering
* Algorithms and data structures
* Databases

The original artifact is a Python and MongoDB dashboard that displays animal shelter data and supports rescue-animal selection.

## Published Narratives and Enhancements

### Enhancement One Narrative: Software Design and Engineering

Enhancement One improves the structure of the original dashboard by refactoring the project into a more organized, layered design. The enhanced version separates the application entry point, database access layer, configuration settings, rescue filtering logic, and controller responsibilities into separate modules.

[View Enhancement One](enhancement-one.md)

### Enhancement Two Narrative: Algorithms and Data Structures

Enhancement Two improves the rescue-animal selection process by adding matching, scoring, and ranking logic. Instead of only filtering records, the enhanced version evaluates animal records against rescue criteria, assigns scores, tracks matched traits, and ranks the strongest candidates first.

[View Enhancement Two](enhancement-two.md)

### Enhancement Three Narrative: Databases

Enhancement Three improves the MongoDB database access layer by adding safer query construction, allowed field validation, projection support, result limits, safer update handling, and environment-based configuration.

[View Enhancement Three](enhancement-three.md)
